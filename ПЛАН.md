# Конвейер канала «Да ну, правда?!» - план (18.10.2026)

Цель: каждый день на YouTube сами выходят **3 Shorts** и длинные ролики, сколько позволяет
бесплатный голос Google. Компьютер Руслана может быть выключен.

## Кто что делает

| Кто | Что | Как часто |
|---|---|---|
| Claude (в сессии с Русланом) | 6-7 сценариев с проверенными фактами + план кадров, кладёт в очередь | раз в неделю |
| GitHub Actions (бесплатное облако) | озвучка, проверка кадров Gemini, сборка, Shorts в Buffer, заполнение YouTube | сам, по расписанию |
| Руслан | перетащить готовый длинный ролик в Studio (ссылка придёт в Telegram), конечная заставка | ~1 мин на ролик |

## Как идёт один ролик

1. **Очередь.** Папка ролика: `озвучка.txt`, `план.json` (кадры по абзацам, ссылки Pexels), название, описание.
2. **Озвучка** - каждый день в 12:10 по Астане (сброс лимита Google): Gemini Orus, по абзацу за запрос,
   ~12 абзацев в день. Проверка Whisper на повторы и пропуски. Кривой абзац - переозвучка на следующий день.
3. **Кадры.** Клипы скачиваются с Pexels, Gemini смотрит стоп-кадр каждого: не то животное - берётся
   запасной клип из плана. Проверено 18.10: 4 подмены из 4 пойманы (ослы вместо гиены, рыбки вместо акулы).
4. **Сборка** - когда весь голос готов: длинный ролик 16:9, 4-5 Shorts, обложка, описание с главами.
   Файлы - в «Релизы» репозитория (публичная ссылка, бесплатно, до 2 ГБ на файл).
5. **Shorts** - 3 в день через Buffer (10:00, 15:00, 20:00 по Астане), в описании ссылка на полный ролик.
   Бесплатный Buffer держит 10 постов в очереди - конвейер доставляет по мере выхода.
6. **Длинный ролик** - в Telegram приходит ссылка на файл. Руслан перетаскивает его в Studio черновиком
   (название не трогать). Конвейер раз в час смотрит черновики, находит ролик, ставит название, описание,
   обложку, плейлисты, открывает и встраивает в цепочку «Следующее видео».
7. **Сбой** (кончились сценарии, Gemini не ответил, сборка упала) - сообщение в Telegram.

## Темп

Голос: ~12 абзацев в день = ~6 длинных роликов в неделю. Из каждого 4-5 Shorts = ~25-30 в неделю,
нужно 21 (3 в день) - с запасом. Значит, мне нужно 5-6 сценариев в неделю.

## Что нужно от Руслана

## Ограничения - честно

- Расписание GitHub может запускаться с опозданием до ~30-60 минут - для нас не важно.
- Бесплатная сборка без лимита минут - только в открытом репозитории: код и тексты видны всем, ключи нет.
- Если в репозитории 60 дней нет изменений, GitHub выключает расписание; конвейер сам делает изменения
  каждый день, так что не грозит.
