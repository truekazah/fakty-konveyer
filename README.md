# Конвейер «Да ну, правда?!» (github.com/truekazah/fakty-konveyer)

Облако GitHub Actions само озвучивает, собирает и выкладывает ролики. План и решения - `ПЛАН.md`,
что делает Руслан - `ШАГИ-РУСЛАНА.md`.

## Расписание (сам, без компьютера)

| Что | Когда | Скрипт |
|---|---|---|
| Озвучка ~12 абзацев (Gemini Orus) + сборка одного готового ролика + релиз + сообщение в Telegram | каждый день 12:15 по Астане | `daily.yml` → `scripts/daily.py` |
| Черновик Руслана в Studio → заполнить и открыть; Shorts в Buffer по 3 в день одной пачкой (с 10:00; если сегодня не было - сразу) | каждый час | `publish.yml` → `scripts/publish.py` |

Стадии ролика (`queue/<папка>/state.json`): `voice` → `ready` → `prepared` → `built` → `published`
(`test` - не трогать). Сообщения - бот @danu_pravda_konveyer_bot, чат Руслана.

## Как положить пачку роликов (раз в неделю, в сессии с Claude)

Папка `queue/NN-slug/` (латиница, по порядку выхода: `02-zmei`, `03-...`). Имя папки = имя файла,
который Руслан перетащит в Studio, и по нему публикатор находит черновик.

- `script.txt` - 14 абзацев через пустую строку: 1 - хук, 2 - вступление с обещанием, 3-12 - факты,
  13 - раскрытие, 14 - итог и призыв. Числа словами. **Каждый абзац факта начинается с цепляющей фразы** -
  он же начало Short (Short = кусок длинного, без отдельной озвучки, бережёт лимит голоса).
- `plan.json` - `PLAN` [[абзац, [клипы]]]; `"~клип"` - фон без проверки (льды, небо, волны);
  `POOL` {"абзац": [запасные клипы]} - если Gemini забракует; `SUBJ` {"абзац": "что должно быть в кадре"} -
  конкретно («акула», «слон»), не «старое животное»; `CHAPTERS`, `COVER` {clip: "имя_секунда", sec, small, big};
  `SHORTS` [{id, abz: [с, по], title, yt_title (≤100, с #shorts #факты), text, tags, ask}] - 4-5 штук;
  `ask` - вопрос зрителю плашкой в конце Short (без апострофов), плашка тогда 3,8 сек вместо 1,8.
- `stock.json` - {клип: номер Pexels} для всех клипов, включая POOL и обложку.
- `meta.json` - {title (≤100, «... 10 фактов о ...»), intro, tags, playlists, chain_key (кусок названия для цепочки)}.
- `chain.json` (в корне) - порядок цепочки «Следующее видео»; новый ролик дописывается сам при публикации.

Проверка перед отправкой - ударения (правило ударений), факты с источниками, длина 5500-7000 знаков (ролик 6-7 мин; «Скорость» 5720, пачка 19.10 - 6500-7000).

## Грабли

- Секреты ставить только `gh secret set ... --body` из Python и только саму строку ключа
  (файлы ключей начинаются с русских комментариев → «secret is not properly UTF-8 encoded», startup_failure).
- Whisper в облаке открывает звук только через ffmpeg (`audio16k`), иначе PyAV падает на mp3.
- Глушилка звука в конце Short внутри Film.tsx не работает - тишина под плашкой делается ffmpeg в build.py.
- Gemini 3.8 Flash бесплатно видит ~25 картинок в день - для кадров основная 3.5 Flash Lite (11 из 12 верно).
- Пачки голоса по несколько абзацев обрываются - только по абзацу за запрос.
- Buffer берёт видео по ссылке на релиз GitHub (проверено 18.10.2026 черновиком).
